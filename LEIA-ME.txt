JOGO: CARRO DESVIADOR (2D) — Godot 4.x — versão completa
==========================================================

COMO ABRIR
----------
1. Abra o Godot Engine (versão 4.x).
2. Clique em "Importar" e selecione o arquivo project.godot desta pasta.
3. Aperte F5 (ou o botão de Play) para rodar o jogo.

FLUXO DO JOGO
-------------
1. Tela de menu -> ENTER
2. Tela de SELEÇÃO DE CARRO -> setas ESQUERDA/DIREITA trocam o carro,
   ENTER confirma e começa a corrida
3. Jogando: setas ESQUERDA/DIREITA trocam de faixa (3 faixas)
4. Game Over -> ENTER volta pra tela de seleção de carro (pode escolher
   outro carro na próxima tentativa)

OS 3 CARROS
------------
- TURBO (vermelho)     -> troca de faixa mais rápido, ótimo pra desviar
  de última hora.
- EQUILIBRADO (azul)   -> sem vantagem nem desvantagem, o clássico.
- BLINDADO (verde)     -> começa cada corrida com um escudo de 3
  segundos de graça (destrói o primeiro carro que bater nele).

Isso está definido em scripts/GameManager.gd, no array car_options —
dá pra editar nome, cor e os valores de cada um, ou adicionar um 4º,
5º carro (só lembre de ajustar a tela de seleção também, ver abaixo).

ONDE MEXER NO VISUAL DOS CARROS
---------------------------------
- scripts/CarVisual.gd -> o desenho vetorial do carro em si (formato,
  para-brisa, rodas, faróis). Usado tanto pelo carro do jogador quanto
  pelos inimigos e pelos carrinhos de exemplo na tela de seleção.
- scripts/GameManager.gd -> array car_options: cor e nome de cada um
  dos 3 carros selecionáveis.
- scripts/Obstacle.gd -> array visual_colors: cores dos carros inimigos.
- scenes/Main.tscn -> nó "CarSelect" tem 3 filhos (Car1, Car2, Car3),
  que são os carrinhos mostrados na tela de seleção. Se quiser mudar a
  posição deles na tela, mexe no "position" de cada um ali.
- scripts/CarSelectUI.gd -> desenha o destaque (círculo + setinha)
  em volta do carro selecionado na tela de escolha.

OUTROS LUGARES ÚTEIS
----------------------
- scripts/Road.gd         -> pista, faixas, grama.
- scripts/PowerUp.gd      -> os 3 tipos de power-up e os ícones deles.
- scripts/Main.gd         -> menu, seleção de carro, spawn de
  obstáculos/power-ups, transições de estado.
- scenes/Explosion.tscn   -> efeito de partículas ao bater.

ADICIONAR UM 4º CARRO (passo a passo rápido)
-----------------------------------------------
1. Em GameManager.gd, adicione um novo dicionário dentro de car_options
   com name, description, color, lane_speed e start_shield.
2. Em Main.tscn, dentro do nó "CarSelect", duplique um dos nós Car1/2/3
   (Cena > Duplicar Nó no Godot) e reposicione-o (ex: x=440, ou
   reorganize todos os 4 em outra disposição).
3. Em CarSelectUI.gd, adicione o novo nó no array "previews".
Pronto — a lógica de troca (setas esquerda/direita) já usa o tamanho
do array car_options automaticamente.

PERSONALIZAR RÁPIDO
--------------------
- Dificuldade: GameManager.gd -> speed_increase_rate e max_speed.
- Frequência de obstáculos/power-ups: Main.tscn -> ObstacleTimer /
  PowerUpTimer -> wait_time.
- Duração dos power-ups: PowerUp.gd -> apply_effect().
